# Project Rules

이 프로젝트는 중학생 모둠활동 편성을 위한 Skill-Will 기반 설문 및 교사용 해석 자료를 관리한다.

## 작업 시작 시 참고 순서

1. `AGENTS.md`
2. `docs/context.md`
3. `docs/research_basis.md`
4. `docs/progress.md`

## 운영 원칙

- 이 자료는 표준화 심리검사나 학생 평가 도구가 아니라, 교사용 모둠 편성 보조도구로 다룬다.
- 학생에게 제공되는 문서에는 성적, 능력, 평가처럼 낙인으로 읽힐 수 있는 표현을 쓰지 않는다.
- 교사용 문서에는 성적/이해도 자료를 사용할 수 있지만, 학생에게 직접 공개하지 않는 내부 자료로 표시한다.
- 기존 연구도구의 문항을 직접 번역하거나 복제하지 않고, 검증된 구성개념을 교실 맥락에 맞게 재구성한다.
- 신규 산출물이나 동작 기준을 바꾸는 작업 전에는 `docs/context.md` 또는 `docs/research_basis.md`를 갱신한다.
- 작업 종료 시 `docs/progress.md`에 변경 내용, 검증 여부, Git/GitHub 처리 상태를 기록한다.

## 검증 기준

- 학생용 설문은 12문항이며, Will 8문항과 참여 주도성 4문항으로 구성한다.
- 학생용 설문 본문에는 성적, 능력, 평가라는 표현이 없어야 한다.
- 점수화 기준은 X축 Skill, Y축 Will, 점 크기 참여 주도성으로 유지한다.
- 검증을 생략하거나 실행하지 못한 경우 `docs/progress.md`에 이유를 남긴다.

## Git/GitHub

- 작업 완료 후 가능한 경우 변경 내용을 커밋하고 GitHub에 push한다.
- GitHub 원격 저장소가 없거나 인증/네트워크 문제로 push할 수 없으면, 시도한 내용과 다음 조치를 `docs/progress.md`에 기록한다.
