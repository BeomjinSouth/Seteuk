# Skill-Will 기반 모둠 편성 지도

이 자료는 중학생 모둠활동 편성을 돕기 위한 교사용 내부 자료다. 표준화 심리검사가 아니며, 학생을 고정된 유형으로 분류하기보다 현재 활동에서 필요한 지원과 모둠 균형을 살피는 데 사용한다.

## 1. 좌표 구조

```text
                         Will 높음
                  책임감/노력이 안정적임
                              ↑
                              |
                              |
Skill 낮음  도움이 더 필요함  ←   →  설명 가능  Skill 높음
                              |
                              |
                              ↓
                         Will 낮음
                    챙김 지원이 필요함

점 크기 = 참여 주도성
작은 점: 조용히 참여함 / 중간 점: 상황에 따라 참여함 / 큰 점: 먼저 말하고 이끄는 편
```

## 2. 점수 산출

### X축 Skill: 학습 준비도

Skill은 학생 설문으로 측정하지 않는다. 최근 단원평가, 형성평가, 수행 관찰, 교사 판단을 종합해 교사가 입력한다.

| 점수 | 교사용 의미 | 학생용 표현 |
|---:|---|---|
| 1 | 도움 필요 | 함께 확인하며 배우면 좋음 |
| 2 | 기본 가능 | 기본 활동을 해낼 준비가 됨 |
| 3 | 설명 가능 | 친구를 도울 준비가 됨 |

### Y축 Will: 책임감/노력

학생 설문 1-8번 평균을 사용한다.

| 평균 | 수준 | 해석 |
|---:|---|---|
| 1.0-2.4 | 챙김 지원 필요 | 역할, 시간, 확인 절차를 구체적으로 잡아 줄 필요가 있음 |
| 2.5-3.4 | 보통 | 활동 구조가 분명하면 안정적으로 참여할 가능성이 큼 |
| 3.5-5.0 | 책임감 높음 | 맡은 일과 모둠 결과를 꾸준히 챙길 가능성이 큼 |

### 점 크기: 참여 주도성

학생 설문 9-12번 평균을 사용한다.

| 평균 | 점 크기 | 해석 |
|---:|---|---|
| 1.0-2.4 | 작은 점 | 조용히 생각하고 필요할 때 참여하는 편 |
| 2.5-3.4 | 중간 점 | 상황에 따라 말하고 참여하는 편 |
| 3.5-5.0 | 큰 점 | 먼저 말문을 열거나 진행을 돕는 편 |

## 3. 모둠 편성 원칙

- 각 모둠에 Skill 3 학생이 과도하게 몰리지 않게 한다.
- Will이 높은 학생이 한 모둠에만 몰리지 않게 한다.
- 큰 점 학생이 너무 많이 모이면 주도권 충돌 가능성을 본다.
- 작은 점 학생만 모이면 대화 시작을 위한 역할 카드나 첫 질문을 제공한다.
- Skill 1 + Will 낮음 학생은 구조화된 역할, 가까운 동료 지원, 짧은 확인 주기를 함께 배치한다.
- Skill 3 + Will 높음 학생에게 설명과 진행을 모두 맡기지 않는다. 도움 역할을 주더라도 부담이 한 사람에게 쏠리지 않게 한다.

## 4. 좌표별 교사 개입

| 위치 | 현재 모습 | 추천 지원 |
|---|---|---|
| Skill 높음 + Will 높음 | 해낼 준비와 책임감이 모두 안정적임 | 자율 역할을 주되 부담이 몰리지 않게 조절 |
| Skill 낮음 + Will 높음 | 하려는 마음은 높지만 내용 도움이 필요함 | 설명 가능한 친구와 짝지어 연습 기회 제공 |
| Skill 높음 + Will 낮음 | 해낼 수 있지만 참여 지속이 약할 수 있음 | 역할의 의미, 마감, 책임 범위를 분명히 제시 |
| Skill 낮음 + Will 낮음 | 내용과 참여 모두 가까운 지원이 필요함 | 작은 역할, 짧은 목표, 자주 확인하는 구조 제공 |

## 5. 학생용 피드백 문구

학생에게는 Skill 좌표나 교사용 점수를 직접 보여주지 않는다. 아래 문구는 필요할 때 자기이해 카드나 개별 피드백에 사용할 수 있다.

| 상황 | 피드백 문구 |
|---|---|
| Will 높음 | 맡은 일을 꾸준히 챙기는 힘이 보여요. 모둠에서 믿고 맡길 수 있는 역할을 해낼 수 있어요. |
| Will 보통 | 역할과 시간이 분명할 때 더 안정적으로 참여할 수 있어요. 시작 전에 할 일을 함께 확인해 봅시다. |
| Will 지원 필요 | 작은 역할부터 차근차근 해내면 좋아요. 오늘은 한 가지 일을 끝까지 해 보는 것을 목표로 해 봅시다. |
| 참여 주도성 큼 | 먼저 말문을 열고 방향을 잡는 힘이 있어요. 친구들이 말할 기회도 함께 만들어 주면 더 좋아요. |
| 참여 주도성 중간 | 상황에 따라 말하고 듣는 균형을 잡을 수 있어요. 모둠이 멈췄을 때 한 번씩 의견을 내 봅시다. |
| 참여 주도성 작음 | 조용히 생각하는 힘이 있어요. 생각한 내용을 짧게라도 말하거나 기록으로 남기면 모둠에 큰 도움이 됩니다. |
