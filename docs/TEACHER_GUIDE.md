# 교사용 사용 안내

## 로그인

- 학교에는 `성호중학교`를 입력한다.
- 아이디에는 본인 한글 교사 이름을 입력한다.
- 비밀번호에는 학교 공용 비밀번호를 입력한다.
- 로그인 후 처음에는 `학생 관리`에서 담당 수업 반을 선택한다.

## 수업 반 등록

- 성호중학교 2026학년도 명렬표는 공용 명부로 준비되어 있다.
- 업로드 없이 해당 학년, 반, 교과를 선택해 수업 반으로 등록한다.
- 등록한 수업 반은 `학생 관찰 기록`과 `AI 세특 생성`에서 사용된다.

## 학생 관찰 기록

- `학생 관찰 기록`에서 수업 반을 선택하고 차시별 활동 내용을 입력한다.
- 활동 칸은 빈칸, 참여, 매우 잘함으로 기록한다.
- 성장 기록은 선택한 학생의 관찰 메모와 쿠키 기록을 남기는 용도로 사용한다.
- 관찰 메모는 나중에 세특 생성 시 근거 자료로 쓰인다.

## 단원 Context 관리

- `/examples`의 `단원 context 관리`에서 학년, 학기, 교과별 단원 목록을 확인한다.
- JSON을 붙여넣거나 업로드하면 필수값(`grade`, `semester`, `subject`, `unit`, `concepts`)과 중복 id를 검증한 뒤 교사 수정본으로 저장한다.
- 단원명, 핵심 개념, 세부 단원, 학습 초점, 가능 활동, 성취기준은 교사 계정의 override로 저장되며 기본 JSON 자체는 바뀌지 않는다.
- 잘못 수정한 단원은 `기본값 복원`으로 교사 override만 삭제할 수 있다.
- 기존 학년·학기 보조 메모는 선택 단원이 없을 때만 fallback context로 사용된다.

## AI 세특 생성

- `AI 세특 생성`에서 특정 반 탭을 선택하면 현재 반의 학년, 학기, 교과에 맞는 단원 context 칩이 표시된다.
- 세특 생성에 사용할 단원만 선택하면 해당 반과 학기 기준으로 저장된다. 다른 반이나 다른 학기에는 섞이지 않는다.
- 선택 단원은 수업 배경으로만 사용된다. 학생별 관찰 메모나 입력 자료에 행동이 있을 때만 단원 개념과 연결된다.
- 생성 전 입력 칸에 실제 관찰 내용과 수행 내용을 확인한다.
- 생성 결과는 직접 수정할 수 있고, 저장 후 맞춤법, 금지어, 유사도, RAG 검토 기능을 사용할 수 있다.
- 점수, 등급, 수상, 시험 문항 번호 등 학교생활기록부에 부적절한 정보는 입력 단계에서 제외한다.

## 프롬프트 설정

- `/settings/ai`에서 세특 생성 프롬프트를 고른다.
- `기본 설정`은 학교 공통 기본 프롬프트 `cross-curricular-seteuk-v2.3`을 읽기 전용으로 사용한다.
- `내 프롬프트`는 본인 계정에서만 쓰는 개인 프롬프트를 작성하고 저장한다.
- 개인 프롬프트는 다른 교사 계정에 보이지 않는다.
- 모델, max output tokens, reasoning effort는 관리자만 수정한다.
- `AI 예시 양식`의 기본값은 관찰 가능한 행동 중심의 중립 예시이며, 짧은 입력에서도 학년·교과 맥락 안에서 교과 내용이 보이도록 돕는다.
- 실제 학생 입력이 짧더라도 학년과 교과명이 있으면 넓은 교과 주제를 문장 맥락으로 쓰되, 입력에 없는 이해도, 역량, 리더십은 생성하지 않는다.
- `1회`, `3차시` 같은 횟수 표현과 `활동지 작성`, `발표 참여`, `수업에 열심히 참여함`만 반복하는 문장은 기본 프롬프트에서 피하도록 설정되어 있다.

## 금지어와 관리자

- `/settings`의 금지어 목록은 세특 금지 표현 검사에 사용된다.
- 기본 금지어에는 과장 표현, 서열·점수 표현, 부정적 단정, 미래 예측, 직접 조언 표현이 포함된다.
- 관리자 권한은 기존 관리자가 `/settings`에서 교사 이름으로 추가하거나 해제한다.
- 최초 관리자 `박범진` 계정은 안전을 위해 해제할 수 없다.

## 문제가 있을 때

- 담당 수업 반 학생이 보이지 않으면 먼저 `학생 관리`에서 수업 반 등록 상태를 확인한다.
- 저장이 되지 않으면 새로고침 후 다시 로그인하고 같은 작업을 반복한다.
- 운영 배포에서 저장 API가 `503`을 반환하면 Supabase 환경변수 설정을 관리자에게 확인한다.
