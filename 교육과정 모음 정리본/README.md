## 참고

NCIC의 2026.01 중학교 노드는 교과 각론 없이 총론만 제공하므로, 교과 각론은 2022.12 고시본을 기준으로 수집했습니다. 최신 총론 PDF는 `참고_비교과` 폴더에 함께 보관했습니다.

정보, 한문, 환경, 보건, 진로와 직업 성취수준은 NCIC에서 `(중고)` 공용 게시글로 제공되므로, 중학교 성취수준 PDF와 공용 연구보고서만 저장했습니다. 모든 대상 교과에 PDF가 있어 HWP는 내려받지 않았습니다.
