# Skill-Will 기반 중학생 모둠 편성 설문 Context

## 목적

중학생 모둠활동을 구성할 때 학생의 학습 준비도, 책임감/노력, 참여 주도성을 함께 고려할 수 있는 교사용 보조자료를 만든다.

## 최종 모델

- X축: Skill, 즉 학습 준비도
- Y축: Will, 즉 책임감/노력
- 점 크기: 참여 주도성
- 점 색: 사용하지 않음

## 사용 방식

- 학생은 `survey/student_survey.md`의 12문항에 5점 척도로 응답한다.
- 교사는 별도 자료를 바탕으로 Skill 점수를 1-3단계로 입력한다.
- Will 점수는 학생 설문 1-8번 평균으로 계산한다.
- 참여 주도성은 학생 설문 9-12번 평균으로 계산하고 점 크기로 표현한다.
- 결과는 교사용 내부 분석과 학생용 자기이해 피드백으로 나누어 사용한다.

## 비사용 범위

- 표준화 심리검사로 사용하지 않는다.
- 학생 선발, 등급화, 생활기록부 기록 등 고위험 의사결정에 단독으로 사용하지 않는다.
- 성적 정보를 학생에게 좌표나 점 크기로 직접 공개하지 않는다.
