# 교육과정 모음 정리본

이 폴더는 NCIC 국가교육과정정보센터 등 공식 공개 출처에서 내려받은 중학교 교육과정 PDF 원본과, 이를 바탕으로 만든 교과별 단원 정리 산출물을 보관합니다.

## 현재 수집본

### 교육과정 고시 PDF

- 위치: `2022_개정_중학교_교육과정_PDF/`
- 기준: 2022 개정 교육과정, 중학교 2022.12 교과 각론
- 용도: 성취기준 원문 확인
- 교과 PDF: 17개
- 참고 PDF: 3개
- 매니페스트: `2022_개정_중학교_교육과정_PDF/DOWNLOAD_MANIFEST.md`
- 기계 판독용 목록: `2022_개정_중학교_교육과정_PDF/manifest.json`

### 교육과정 단원 정리본

- 위치: `교육과정_단원_정리/`
- 기준: `2022_개정_중학교_교육과정_PDF/교과`의 17개 교과 PDF
- 주 산출물: `교육과정_단원_정리/교과별_XLSX/`의 교과별 XLSX 17개, `교육과정_단원_정리/교과별_JSON/`의 교과별 JSON 17개와 `index.json`
- 보조 산출물: 교과별 Markdown 17개, 통합 XLSX 1개
- 통합표: `교육과정_단원_정리/중학교_교과별_교육과정_단원_정리.xlsx`
- 기계 판독용 데이터: `교육과정_단원_정리/unit_summary_data.json`
- 교과별 JSON 구조: `metadata`, `hierarchy`, `units`를 포함하며 원본 행의 14개 필드를 보존
- 정리 기준: 대단원은 교육과정 영역, 중단원은 내용 요소 또는 성취기준 묶음, 소단원은 성취기준 코드 단위로 변환
- 설명 방식: 성취기준 원문을 길게 옮기지 않고 핵심 개념, 수행 활동, 태도·적용·평가 유의점을 교사용 요약 문장으로 정리

### 성취수준 PDF

- 위치: `2022_개정_중학교_성취수준_PDF/`
- 기준: 2022 개정 교육과정, 중학교 성취수준, NCIC 성취수준 게시물
- 성취수준 PDF: 17개
- 성취수준 개발 연구보고서 PDF: 17개
- 매니페스트: `2022_개정_중학교_성취수준_PDF/DOWNLOAD_MANIFEST.md`
- 기계 판독용 목록: `2022_개정_중학교_성취수준_PDF/manifest.json`
- 과목별 연결표: `2022_개정_중학교_성취수준_PDF/SUBJECT_INDEX.md`
- 재수집 스크립트: `2022_개정_중학교_성취수준_PDF/download_from_ncic.ps1`

## 포함 교과

- 교육과정 고시 PDF: 국어, 수학, 영어, 사회, 도덕, 과학, 체육, 음악, 미술, 기술·가정, 정보, 생활 외국어, 한문, 환경, 보건, 진로와 직업, 한국어 교육과정.
- 성취수준 PDF: 국어, 수학, 영어, 사회, 도덕, 역사, 과학, 체육, 음악, 미술, 기술·가정, 정보, 생활 외국어, 한문, 환경, 보건, 진로와 직업.

## 참고

NCIC는 2026.01 중학교 총론은 제공하지만 교과 각론은 별도 최신본 없이 2022.12 고시본을 기준으로 제공합니다. 최신 총론 PDF는 참고용 폴더에 함께 보관했습니다.

정보, 한문, 환경, 보건, 진로와 직업 성취수준은 NCIC에서 `(중고)` 공용 게시물로 제공하므로 중학교 성취수준 PDF는 공용 연구보고서만 저장했습니다. 모든 대상 교과는 PDF가 있어 HWP는 내려받지 않았습니다.
