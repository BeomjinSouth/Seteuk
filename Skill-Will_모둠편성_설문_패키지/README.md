# Skill-Will 모둠 편성 설문 패키지

이 폴더는 중학생 모둠활동 편성을 위한 자료 묶음입니다.

## 먼저 볼 파일

1. `01_학생용/student_survey.md`
   - 학생에게 배부할 12문항 설문입니다.
   - 학생에게는 성적, 능력, 평가라는 표현을 쓰지 않도록 구성했습니다.

2. `02_교사용/teacher_guide.md`
   - Skill-Will 좌표 해석, 점수화 기준, 모둠 편성 원칙, 학생 피드백 문구가 들어 있습니다.

3. `02_교사용/scoring_template.csv`
   - 학생별 응답과 교사용 Skill 점수를 입력해 Will 평균, 참여 주도성 평균, 점 크기를 계산하는 템플릿입니다.

## 참고 자료

- `03_근거와_운영/research_basis.md`: 연구 기반과 해석상 주의
- `03_근거와_운영/context.md`: 프로젝트 목적과 사용 범위
- `03_근거와_운영/AGENTS.md`: 작업 운영 규칙
- `03_근거와_운영/progress.md`: 작업 진행 기록

## 사용상 주의

- 이 자료는 표준화 심리검사가 아니라 교사용 모둠 편성 보조도구입니다.
- 학생에게 성적 기반 Skill 좌표를 직접 공개하지 않습니다.
- 설문 결과는 학생을 고정된 유형으로 분류하기보다, 현재 모둠활동에서 필요한 지원을 파악하는 자료로 사용합니다.
