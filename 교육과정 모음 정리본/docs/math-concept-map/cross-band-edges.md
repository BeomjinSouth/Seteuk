# 학년군 사이 연결 (cross-band edges)

초등·중학교·고등 공통 과목의 미시 concept 데이터셋은 각각 별도 파일이지만,
2022 개정 수학과 교육과정(별책8) 원문은 앞·뒤 학년군의 학습 내용을 직접 지목하는 문장을 담고 있다.
이 산출물은 그 직접 서술에만 근거해 데이터셋 경계를 잇는 선수 관계 edge를 모은 것이다.

## 근거 규칙

- 모든 edge는 성취기준 해설, 적용 시 고려 사항, 또는 과목 성격의 직접 연계 문장에 근거한다.
- 성취기준 해설·고려 사항이 앞 학년군 학습을 명시적으로 지목하면 `high`,
  과목 성격의 심화·체계화 서술처럼 특정 성취기준 근거가 아니면 `medium`으로 둔다.
- 모델의 배경 지식으로 임의 연결을 만들지 않는다(AGENTS.md Math Concept Map Scope Rules).

## 근거 문장

- `공약수와 최대공약수` → `소인수분해로 최대공약수와 최소공배수 구하기`: 초등학교에서 학습한 최대공약수의 개념을 바탕으로 소인수분해를 이용해 최대공약수를 구하게 한다 [printed p. 33; [9수01-02] 성취기준 해설]
- `공배수와 최소공배수` → `소인수분해로 최대공약수와 최소공배수 구하기`: 초등학교에서 학습한 최소공배수의 개념을 바탕으로 소인수분해를 이용해 최소공배수를 구하게 한다 [printed p. 33; [9수01-02] 성취기준 해설]
- `실수` → `복소수`: 복소수의 성질과 사칙연산은 중학교에서 학습한 실수의 성질과 사칙연산과 연계하여 이해하게 한다 [printed p. 61; [10공수1-02-01] 적용 시 고려 사항]
- `근호를 포함한 식의 사칙계산` → `복소수의 사칙연산`: 복소수의 사칙연산은 중학교에서 학습한 실수의 사칙연산과 연계하여 이해하게 한다 [printed p. 61; [10공수1-02-01] 적용 시 고려 사항]
- `다항식의 곱셈` → `다항식의 사칙연산`: 다항식의 곱셈은 중학교에서 학습한 내용을 토대로 고등학교에서 추가된 내용을 이해하게 한다 [printed p. 60; [10공수1-01-03] 적용 시 고려 사항]
- `인수분해` → `다항식의 인수분해`: 다항식의 인수분해는 중학교에서 학습한 내용을 토대로 고등학교에서 추가된 내용을 이해하게 한다 [printed p. 60; [10공수1-01-03] 적용 시 고려 사항]
- `다항식의 각 항을 단항식으로 나누기` → `조립제법`: 조립제법은 중학교에서 학습한 다항식을 단항식으로 나누는 연산과 연계하여 이해하게 한다 [printed p. 60; [10공수1-01-03] 적용 시 고려 사항]
- `연립일차방정식` → `연립일차부등식 풀기`: 연립부등식은 중학교에서 학습한 연립일차방정식 내용을 토대로 이해하게 한다 [printed p. 62; [10공수1-02-09] 적용 시 고려 사항]
- `경우의 수` → `합의 법칙`: 중학교에서 학습한 경우의 수와 연계하여 합의 법칙을 간단히 다룬다 [printed p. 62; [10공수1-03-01] 적용 시 고려 사항]
- `경우의 수` → `곱의 법칙`: 중학교에서 학습한 경우의 수와 연계하여 곱의 법칙을 간단히 다룬다 [printed p. 62; [10공수1-03-01] 적용 시 고려 사항]
- `경우의 수` → `순열`: '자료와 가능성' 영역에서 학습한 경우의 수가 순열과 조합을 활용하는 방법으로 체계화된다 [printed p. 57 과목 성격]
- `이차방정식` → `이차방정식과 이차함수의 관계`: 중학교 '변화와 관계' 영역에서 학습한 방정식이 심화되고 다양한 유형으로 다루어진다 [printed p. 57 과목 성격]
- `이차함수` → `이차방정식과 이차함수의 관계`: 중학교 '변화와 관계' 영역에서 학습한 이차함수가 이차방정식과 연결되어 심화된다 [printed p. 57 과목 성격]
- `일차함수의 그래프` → `두 직선의 평행 조건과 수직 조건`: 두 직선의 평행 조건과 수직 조건은 중학교에서 학습한 일차함수의 그래프, 직선의 방정식과 연계하여 다룬다 [printed p. 65; [10공수2-01-02] 적용 시 고려 사항]
- `일차함수와 일차방정식의 관계` → `두 직선의 평행 조건과 수직 조건`: 두 직선의 평행 조건과 수직 조건은 중학교에서 학습한 일차방정식과 일차함수의 그래프와 연계하여 다룬다 [printed p. 65; [10공수2-01-02] 적용 시 고려 사항]
- `함수` → `함수(두 집합 사이의 대응)`: 함수의 개념은 중학교에서 학습한 내용을 확장하여 두 집합 사이의 대응 관계로 이해하게 한다 [printed p. 67; [10공수2-03-01] 성취기준 해설]
