# 재취학 학생 학교생활기록부 삭제 후 재입력 양식
> 학생이 학업을 중단할 경우에도 원적교에서는 해당 학생이 재학할 때까지의 각종 자료를 교육정보시스템 등에 입력하여 보관해야 합니다(해당 학년도의 학교생활기록부 입력 내용은 해당 학년도의 학교생활기록부를 적용하며, 해당 학생의 학업 중단 학년도가 2025학년도라고 가정한 답변임. 단, 2026학년도에도 해당 내용에 대해서는 변경된 것이 없음.).

## Question
QnA 게시판에서 확인 결과 중복되지 않은 창의적 체험활동 자료 중 자율활동 및 진로활동은 별도의 누가기록 없이 이수시간을 수기로 추가하여 입력 후 중복되지 않는 내용을 당해년도 특기사항에 입력한다고 되어 있습니다.
1. 이수시간을 수기로 추가하여 입력하는 영역이 특기사항 부분인가요?
2. 예를 들어 이수시간은 3시간이 있는데, 이 부분에 대한 특기사항이 없을 경우 특기사항에 뭐라고 입력하나요?
입력예시)
자율의 경우 - 재취학 이전에 자율활동 3시간 이수함.
동아리의 경우 - (동아리명칭)(2시간) 재취학 이전에 동아리활동 2시간 이수함.
주어진 예시가 없어서 이렇게 자유로운 형식으로 입력하면 되나요?
## Answer Excerpt
안녕하십니까? 학교생활기록부 종합지원센터입니다. 귀하께서 질의하신 내용에 대한 검토 결과를 다음과 같이 알려드립니다. 귀하의 질의 내용은 ‘재취학 학생의 중복되는 기간에 해당하는 자료 삭제 후 창의적 체험활동상황의 중복되지 않는 기간에 해당하는 이수시간 처리 방법’에 대한 것으로 이해됩니다. 학생이 학업을 중단할 경우에도 원적교에서는 해당 학생이 재학할 때까지의 각종 자료를 교육정보시스템 등에 입력하여 보관해야 합니다(해당 학년도의 학교생활기록부 입력 내용은 해당 학년도의 학교생활기록부를 적용하며, 해당 학생의 학업 중단 학년도가 2025학년도라고 가정한 답변임. 단, 2026학년도에도 해당 내용에 대해서는 변경된 것이 없음.). 이에 따라, 창의적 체험활동상황의 각 영역별 특기사항은 모든 학생에 대해 입력해야 하므로 학업 중단 전까지 창의적 체험활동상황의 각 영역에 1시간이라도 참여한 경우 관찰·평가한 내용을 바탕으로 특기사항을 입력해야 하며, 1시간이라도 참여하지 못한 학생의 경우(이수시간이 0시간인 경우) 그 사유를 특기사항에 입력해야 합니다(즉, 해당 상황은 입력 누락으로 판단되며, 이전 학년도 자료와 관련된 세부 처리 방법은 학교의 학업성적관리위원회에서 결정할 사항임.). 또한, 2025학년도에는 창의적 체험활동상황의 각 영역에 ‘시간’을 입력해야 했으나, 2026학년도에는 규정이 개정됨에 따라 창의적 체험활동상황의 각 영역에 ‘시간’을 입력하지 않습니다(2026학년도 1학년의 경우 학교생활기록부 서식 자체가 변경됨에 따라 ‘시간’ 항목 자체가 학교생활기록부에 표출되지 않고, 2~3학년의 경우 기존 서식을 적용하므로 ‘시간’ 항목이 있지만 해당란에 ‘·’이 입력됨. 아직은 나이스 시스템 개선이 이루어지지 않았으며 차후 개선될 예정임.). 즉, 2025학년도까지는 나이스에...
