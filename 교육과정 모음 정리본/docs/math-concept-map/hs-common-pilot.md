## 범위와 출처 규칙 (2026-07-06 사용자 결정)

- 고등학교 선택 과목(일반·진로·융합)은 이 작업에서 제외한다(AGENTS.md Math Concept Map Scope Rules).

- 모든 concept과 edge는 별책8 원문의 성취기준·해설·적용 시 고려 사항·용어와 기호에 근거하며,
