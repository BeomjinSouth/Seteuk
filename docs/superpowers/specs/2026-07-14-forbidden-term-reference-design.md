# 기재 유의어 참고 규칙 설계

## 목표

교사가 기재 금지어 검사를 실행할 때, 제공된 2023 기재 유의어 자료의 상호명, 서비스명, 영문 및 약어를 발견하면 일반화한 대체표현을 함께 안내한다.

## 설계

- 기존 `DEFAULT_FORBIDDEN_WORDS`는 교사가 편집하는 기본 금지어 목록으로 유지한다.
- 자료 기반 항목은 `src/lib/forbidden-words.ts`의 별도 규칙 배열로 관리한다. 각 규칙은 원문, 사유, 대체표현을 가진다.
- `/api/forbidden`은 이 규칙을 기존 하드코딩 검사와 함께 실행하고, 자료 기반 항목의 사유를 `상호명·영문 기재 유의어`로 반환한다.
- 영문 자동 검사에서는 자료 기반 항목을 제외해 같은 표현이 두 번 나오지 않게 한다.

## 범위와 검증

- 제공된 화면에서 확인되는 상호명·서비스명·영문/약어와 대체표현을 반영한다.
- 기존 API 응답 형식(`word`, `reason`, `suggestion`)은 바꾸지 않는다.
- 단위 테스트는 유튜브·Zoom·TED와 ESG·UN의 안내문을 검증한다.
