# (재상담) 전입 학생의 생활기록부 내용 수정 문의
> 학교생활기록부 각 항목의 당해 학년도 자료 입력 및 입력된 자료의 수정, 삭제 등은 항목별 입력 주체의 고유 권한으로 입력 주체의 평가 내용을 임의로 수정할 수 있는지 여부는 기재요령에서 제시하고 있지 않습니다.

## Question
안녕하세요^^ 재상담 드립니다.
제가 궁금한 부분은,
예를 들어,
2026.03.08.자 A학교 전출
2026.03.09.자 B학교 전입
(당해학년도 재학생 전입) 위와 같은 학생이 있을 때,
2026학년도(당해학년도) A학교(전출교)에서 입력한 창체 특기사항, 과세특, 행동특성 등의 내용에서,
누락이나 추가 입력 요청이 아니라,
A학교(전출교)에서의 내용이 부실하거나 너무 방대할 경우,
B학교(현재 학교(전입교))에서 내용을 새로 입력하는 것에 제한이 있을 수 있는 경우가 있으므로,
A학교(전출교)에서 입력해 온 일부 내용 또는 전체 내용 삭제, 또는 수정을
B학교(현재 학교(전입교))에서 담당 교사(담임 및 교과, 동아리 담당 등)가 ‘정정 절차’없이 자율적으로 수정할 수 있는건가요?
아니면, 당해학년도라도 ‘정정 절차’를 거쳐서 A학교(전출교) 입력 내용을 수정해야 하는 건가요?

전입생의 이전 학년도 자료의 정정은 전출교에서 자료를 받아 전입교에서 처리합니다. 만약 당해 학년도에 누락된 자료가 있다면 전출교로부터 자료 입력 관련 공문을 받아 입력합니다. 전입생의 당해 학년도 자료 입력의 주체(학급담임교사)는 전출교와 전입교에 모두 존재합니다만, 전출교에서 보내준 당해학년도 자료에 오류가 있는 경우 전출교에 다시 자료를 요청하실 수 있습니다. 다만 전출교에서 자료를 다시 받을 수 없거나 기타 불가피한 경우, 전입교의 학업성적관리위원회 심의를 통해 결정도 가능함을 안내하여 드립니다.
