# 교과서 반입 점검 결과 (2026-07-07)

사용자 다운로드 폴더에서 수학 교과서를 찾아 사본을 만들고, 프로젝트 반입 절차(교과서_원본/ + 매니페스트 + 감사)로 확인 가능한 항목을 모두 점검한 기록이다.

## 결론 요약

- 다운로드 폴더에는 수학 교과서 PDF가 **2015 개정판과 2022 개정판이 섞여** 있었다.
- 우리 개념 map은 **2022 개정** 기반이므로, 2022 개정 완결본만 반입했다: **중1 5단원 + 중2 5단원, 총 10개 PDF**.
- `15개정` 표기가 있는 교과서(이준열·김화경 등)와 고등 선택 과목(인공지능 수학·산업수학)은 반입하지 않았다.
- 반입 파일은 모두 유효 PDF·해시 기록·감사 통과 상태지만, **공개 출처 URL이 없어 정식 추출 게이트는 열지 않았다**(`needs_manifest_metadata`). 저작권·출처 확인은 사용자 결정 사항이다.

## 판(2015/2022) 식별 방법

- 파일명 `15개정` 표기 → 2015 개정으로 분류(사용 안 함).
- 본문에서 **"핵심 아이디어"**(2022 개정 고유 문구)와 **학년군 표기 "초5~6", "중1~3"**(2022 개정 편제) 확인 → 2022 개정으로 분류.
- 이준열 교과서 p.3은 "이 교과서는 2015 개정 교육과정에 맞추어…"라고 명시 → 제외 확정.

## 감사 결과 (`textbook-source-audit.*`)

- 10개 전부: PDF 헤더 정상, 파일명 규칙 통과, 매니페스트 연결됨.
- `manifest_status = missing_source_metadata`, `intake_status = needs_manifest_metadata`.
- 즉, **공개 출처 URL과 attachment id가 채워지면** 감사가 `ready_for_textbook_extraction`으로 바뀌어 본문 근거 추출을 시작할 수 있다. 그 전까지는 개념 map에 교과서 근거를 붙이지 않는다.

## 내용 사용성 확인 (저작권 규칙: 개념명·쪽수만)

- 교과서는 단원 앞머리에 **계통도(배운 내용/배울 내용)**로 학년 간 위계를 스스로 제시한다.
- 중1 수와 연산 p.3 "배운 내용" 상자: **최대공약수·최소공배수를 "초5~6" 학습 내용으로 명시**한다. 이는 우리 cross-band edge(`e56_num_common_divisor`/`e56_num_common_multiple(초5-6)` → `m1_num_find_gcd_lcm_prime_factorization(중1)`, `[9수01-02]` 해설 근거)를 교과서가 독립적으로 뒷받침함을 뜻한다.
- 중2 유리수와 순환소수 p.2 계통도: 이후 "중3 분수와 소수의 곱셈과 나눗셈" 등으로 연결. 중2 도형의 닮음·피타고라스 p.2 계통도: "중3 작도와 합동, 피타고라스, 평면도형의 성질"로 연결.
- 결론: 교과서 본문은 우리 개념·위계와 정합적이며, 출처 확인만 끝나면 근거 보강 자료로 바로 활용 가능하다.

## 다음 단계 (사용자 확인 필요)

1. 각 교과서의 공개 출처 URL(또는 사용 근거)을 `TEXTBOOK_SOURCE_MANIFEST.csv`의 `source_url`·`attachment_id`에 채운다. 채우면 감사가 추출 가능 상태로 바뀐다.
2. 출판사 확정(표지/판권면 확인) 후 파일명 `미확인`을 실제 출판사로 교체한다.
3. 추출 시작 시 `textbook-evidence-workplan.*`의 rank 상위 단원부터 개념명·짧은 정의·쪽수·관계 근거만 반영한다(원문 전재 금지).
