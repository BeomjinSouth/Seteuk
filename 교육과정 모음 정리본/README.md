# 교육과정 모음 정리본

이 폴더는 NCIC 국가교육과정정보센터에서 내려받은 중학교 교육과정/성취수준 PDF 원본 모음입니다.

## 현재 수집본

### 교육과정 고시 PDF

- 위치: `2022_개정_중학교_교육과정_PDF/`
- 기준: 2022 개정 교육과정, 중학교, 2022.12 교과 각론
- 용도: 성취기준 원문 확인
- 교과 PDF: 17개
- 참고 PDF: 3개
- 매니페스트: `2022_개정_중학교_교육과정_PDF/DOWNLOAD_MANIFEST.md`
- 기계 판독용 목록: `2022_개정_중학교_교육과정_PDF/manifest.json`

### 교육과정 단원 정리본

- 위치: `교육과정_단원_정리/`
- 기준: `2022_개정_중학교_교육과정_PDF/교과`의 17개 교과 PDF
- 산출물: 교과별 Markdown 17개, 통합 XLSX 1개
- 통합표: `교육과정_단원_정리/중학교_교과별_교육과정_단원_정리.xlsx`
- 기계 판독용 데이터: `교육과정_단원_정리/unit_summary_data.json`
- 정리 기준: 대단원은 교육과정 영역, 중단원은 내용 요소 또는 성취기준 묶음, 소단원은 성취기준 코드 단위로 변환
- 설명 방식: 성취기준 원문을 길게 전재하지 않고 핵심 개념, 수행 활동, 태도·적용·평가 유의점을 교사용 요약 문장으로 정리

## 참고

NCIC의 2026.01 중학교 노드는 교과 각론 없이 총론만 제공하므로, 교과 각론은 2022.12 고시본을 기준으로 수집했습니다. 최신 총론 PDF는 `참고_비교과` 폴더에 함께 보관했습니다.

정보, 한문, 환경, 보건, 진로와 직업 성취수준은 NCIC에서 `(중고)` 공용 게시글로 제공되므로, 중학교 성취수준 PDF와 공용 연구보고서만 저장했습니다. 모든 대상 교과에 PDF가 있어 HWP는 내려받지 않았습니다.
