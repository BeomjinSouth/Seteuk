# 함께 배우기 설문

이 설문은 더 좋은 모둠활동을 준비하기 위한 것입니다. 정답은 없습니다. 최근 모둠활동에서의 내 모습에 가장 가까운 번호를 골라 주세요.

| 번호 | 응답 |
|---|---|
| 1 | 전혀 그렇지 않다 |
| 2 | 별로 그렇지 않다 |
| 3 | 보통이다 |
| 4 | 대체로 그렇다 |
| 5 | 매우 그렇다 |

## 문항

| 번호 | 문항 | 1 | 2 | 3 | 4 | 5 |
|---:|---|:---:|:---:|:---:|:---:|:---:|
| 1 | 모둠에서 내가 맡은 일은 끝까지 하려고 한다. |  |  |  |  |  |
| 2 | 활동에 필요한 준비물, 자료, 역할을 미리 확인한다. |  |  |  |  |  |
| 3 | 활동이 어려워도 바로 포기하지 않고 다시 해 본다. |  |  |  |  |  |
| 4 | 친구와 약속한 일이나 시간을 지키려고 한다. |  |  |  |  |  |
| 5 | 결과물을 내기 전에 빠진 것이 없는지 확인한다. |  |  |  |  |  |
| 6 | 활동 시간에는 내가 할 일에 집중하려고 한다. |  |  |  |  |  |
| 7 | 모르는 것이 있으면 혼자 멈춰 있기보다 친구나 선생님에게 도움을 요청한다. |  |  |  |  |  |
| 8 | 모둠 결과가 잘 나오도록 내 역할 밖의 일도 살펴본다. |  |  |  |  |  |
| 9 | 활동이 시작될 때 내가 먼저 의견을 내는 편이다. |  |  |  |  |  |
| 10 | 모둠이 무엇을 할지 멈춰 있을 때 다음 할 일을 제안하는 편이다. |  |  |  |  |  |
| 11 | 말하지 못한 친구에게 의견을 물어보는 편이다. |  |  |  |  |  |
| 12 | 발표, 진행, 정리의 방향을 잡는 데 먼저 참여하는 편이다. |  |  |  |  |  |
